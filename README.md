# 📊 Unsupervised Clustering of Historical Market States
**Course:** CMPT 455 — Intro to Machine Learning  
**Institution:** MacEwan University  
**Status:** ✅ Completed

## Overview
A machine learning project that applies unsupervised clustering techniques 
to historical S&P 500 market data to identify and classify distinct market 
regimes and trends over time. The goal is to uncover hidden patterns in 
market behavior using clustering algorithms without labeled data.

## Objectives
- Identify distinct market states (regimes) from historical S&P 500 data
- Apply unsupervised clustering to find natural groupings in market behavior
- Determine optimal number of clusters using K-value analysis
- Visualize and interpret each identified market trend
- Analyze the impact of 8 key market variables on each cluster

## Technologies Used
- **Python** — Core programming language
- **Scikit-learn** — Clustering algorithms and ML tools
- **Pandas** — Data loading and manipulation
- **NumPy** — Numerical computations
- **Matplotlib / Seaborn** — Data visualization
- **Jupyter Notebook** — Analysis and documentation

## Methodology
1. **Data Collection** — Historical S&P 500 market data gathered
2. **Data Preprocessing** — Cleaning, normalization, and feature engineering
3. **K-Value Analysis** — Elbow method and silhouette scores to find optimal K
4. **Clustering** — Applied K-Means and other unsupervised algorithms
5. **Visualization** — Plotted clusters and market regime transitions over time
6. **Interpretation** — Analyzed what each cluster represents in market terms

## Key Variables Analyzed
The clustering model was built around 8 key market variables including:
- Price momentum indicators
- Volatility measures
- Volume patterns
- Market trend signals

## Results
- Successfully identified distinct market regimes from historical data
- Each cluster represents a unique market state with characteristic behavior
- Visualizations show clear regime transitions over the S&P 500 history
- Findings provide insights into recurring market patterns

## Key Learnings
- Unsupervised machine learning and clustering techniques
- Financial data preprocessing and feature engineering
- K-Means clustering and optimal K selection
- Data visualization and interpretation of ML results
- Applying ML to real-world financial datasets
